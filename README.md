# Juan Gefaell personal website

This folder is a static website prepared from the WordPress content and media exports. It contains the Home, Research, Publications, CV, and Skateboarding pages, plus individual files for published posts.

## Publish to GitHub Pages

1. Download and install GitHub Desktop if it is not installed.
2. In GitHub Desktop, choose **File → Clone repository**, select `juangefaell/juangefaell.github.io`, and choose a folder on your computer.
3. Copy the contents of this folder into that cloned repository, replacing its existing `index.html`. Keep the `assets`, `posts`, and all `.html` files together.
4. In GitHub Desktop, review the changed files, enter a summary such as `Add personal website`, then choose **Commit to main** and **Push origin**.
5. Wait for GitHub Pages to update, then visit https://juangefaell.github.io.

The WordPress site remains untouched. Review the CV and publication links after publishing; this package links to the exported documents locally.
